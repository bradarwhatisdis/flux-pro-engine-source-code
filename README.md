# Flux Pro Engine — 8 Ball Pool Android Game Mod

Source Code for FluxProEngine8BP.

A root-injected cheat/modification for Miniclip's 8 Ball Pool game with ESP, Auto Play, Auto Queue, Auto Aim, and Dear ImGui overlay.

## Build

```bash
export ANDROID_NDK_HOME=/path/to/ndk/24.0.8215888
./gradlew assembleRelease
```
